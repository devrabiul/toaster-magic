Getting Started

Toaster Magic

Lightweight, dependency-free toast notifications with beautiful themes — the standalone JavaScript version of Laravel Toaster Magic. Works with React, Vue, Next.js, Nuxt, Svelte, or plain JavaScript.

💡 Good to know: zero dependencies, ~5 KB min+gzip, SSR-safe imports, TypeScript types included, and HTML is escaped by default.
⚠️ Live demos disabled: dist/ was not found. Run npm install && npm run build in packages/toaster-magic, then reload this page.

Installation

npm install toaster-magic

Import the module and the stylesheet once:

import { toastMagic } from "toaster-magic";
import "toaster-magic/css"; // or "toaster-magic/css/min"

Quick Start

toastMagic.success("Success!", "Your data has been saved.");
toastMagic.error("Oops", "Something went wrong.");
toastMagic.warning("Heads up", "Storage almost full.");
toastMagic.info("FYI", "A new version is available.");

Per-toast options

Pass an options object as the third argument:

toastMagic.success("Order shipped", "Track your package anytime.", {
  showCloseBtn: true,
  customBtnText: "Track",
  customBtnLink: "/orders/42",
  timeOut: 8000, // ms, overrides the global default
});

React, Vue, Next.js, Nuxt

There is no provider, portal, or <ToastContainer /> component to mount — the container is created automatically on the first toast. Importing is SSR-safe, so the same import works in Next.js and Nuxt; just trigger toasts from client-side code (event handlers, effects). 

import { toastMagic } from "toaster-magic";
import "toaster-magic/css";

export function SaveButton() {
  return (
    <button onClick={() => toastMagic.success("Saved!", "Profile updated.")}>
      Save
    </button>
  );
}
// app/layout.tsx — load the styles once, globally
import "toaster-magic/css";

// Any client component:
"use client";
import { toastMagic } from "toaster-magic";

export function SaveButton() {
  return (
    <button onClick={() => toastMagic.success("Saved!", "Profile updated.")}>
      Save
    </button>
  );
}
<script setup>
import { toastMagic } from "toaster-magic";
import "toaster-magic/css";

function save() {
  toastMagic.success("Saved!", "Your changes are live.");
}
</script>

<template>
  <button @click="save">Save</button>
</template>
// nuxt.config.ts — register the stylesheet globally
export default defineNuxtConfig({
  css: ["toaster-magic/css"],
});

// Then use it in any component or composable:
import { toastMagic } from "toaster-magic";
toastMagic.success("Saved!", "Your changes are live.");

CDN / Script Tag

The global build exposes window.toastMagic and supports declarative data-toast-* triggers:

<link rel="stylesheet" href="https://unpkg.com/toaster-magic/dist/toaster-magic.min.css">
<script src="https://unpkg.com/toaster-magic/dist/toaster-magic.global.js"></script>
<script>
  toastMagic.success("Hello!", "It just works.");
</script>

<!-- Declarative triggers — no JavaScript needed -->
<button
  data-toast-type="success"
  data-toast-heading="Copied"
  data-toast-description="Link copied to clipboard"
  data-toast-close-btn
>Copy</button>
💡 Good to know: an existing window.toastMagicConfig object (as emitted by the Laravel package, snake_case keys included) is picked up automatically, so the CDN build is a drop-in replacement for the Laravel asset.

Configuration

Configure the shared singleton once, anywhere before (or after) the first toast:

import { configure } from "toaster-magic";

configure({
  positionClass: "toast-bottom-end",
  theme: "glassmorphism",
  animation: "slide",
  closeButton: true,
  preventDuplicates: true,
  timeOut: 5000,
  pauseOnHover: true,
  gradientEnable: false,
  colorMode: false,
});
OptionTypeDefaultDescription
positionClassstring"toast-top-end"Where the toast stack is anchored. See Positions.
closeButtonbooleanfalseShow a close button on every toast unless overridden per toast.
preventDuplicatesbooleanfalseSkip a toast when an identical one (type + heading + description) is visible.
showDurationnumber100Delay in ms before the entrance animation plays.
timeOutnumber5000Auto-dismiss timeout in ms.
themestring"default"Visual theme. See Themes.
animationstring"default"Entrance/exit animation. See Animations.
pauseOnHoverbooleantruePause the auto-dismiss timer while the toast is hovered.
gradientEnablebooleanfalseGradient accent styling (default, material, ios, glassmorphism, neon themes).
colorModebooleanfalseColored toast background per type.

Multiple independent instances

import { ToastMagic } from "toaster-magic";

const alerts = new ToastMagic({ theme: "neon", positionClass: "toast-bottom-center" });
alerts.warning("Independent", "This instance has its own config.");

Toast Options

Every option can also be set per toast as the third argument (or inside show()):

OptionTypeDefaultDescription
showCloseBtnbooleanconfig closeButtonShow a close button on this toast.
customBtnTextstring–Label for an action link button (rendered only with customBtnLink).
customBtnLinkstring–URL for the action button. Unsafe URLs are replaced with #.
timeOutnumberconfig timeOutAuto-dismiss ms for this toast.
showDurationnumberconfig showDurationEntrance delay ms for this toast.
avatarstring–Image URL rendered instead of the type icon.
allowHtmlbooleanfalseRender heading/description as raw HTML. Trusted content only.

Themes

Seven built-in themes, switchable at runtime with configure({ theme }). Click one to preview:

configure({ theme: "glassmorphism" }); // default | material | ios | glassmorphism | neon | minimal | neumorphism

Positions

Six anchor positions; start/end are logical properties, so RTL layouts mirror automatically:

configure({ positionClass: "toast-bottom-center" });

Animations

Entrance/exit animation styles, plus a smooth FLIP reflow that glides the stack when toasts are added or removed (automatically disabled for users with prefers-reduced-motion): 

configure({ animation: "bounce" }); // default | slide | fade | pop | bounce

Dark Mode

Set theme="dark" on <body> and toasts follow automatically (this page's theme toggle does exactly that), or override the CSS custom properties yourself: 

<body theme="dark">
/* Or with your own palette */
:root {
  --toast-item-bg: #1e293b;
  --toast-item-color: #f1f5f9;
}

API Reference

MethodDescription
toastMagic.success(heading, description?, options?)Show a success toast.
toastMagic.error(...) / .warning(...) / .info(...)Other toast types, same signature.
toastMagic.show({ type, heading, ... })Fully explicit form.
toastMagic.clear() / .dismissAll()Dismiss all visible toasts.
toastMagic.configure(options) / configure(options)Update the config (the named export targets the shared singleton).
toastMagic.getConfig()A copy of the active configuration.
new ToastMagic(options?)Independent instance with its own config.

Legacy positional signature

For drop-in compatibility with the Laravel asset, the positional form still works:

toastMagic.success(heading, description, showCloseBtn, customBtnText, customBtnLink, timeOut, showDuration, avatar);

Security

Heading, description, and button text are HTML-escaped by default, so passing user-generated content is safe. Opt out per toast with allowHtml: true for trusted content only. customBtnLink and avatar URLs are sanitized — anything that isn't http(s)://, /, or # is replaced with #, which blocks javascript: URLs.
